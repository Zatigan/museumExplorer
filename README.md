# Museum Explorer

## About
This project is related to a course evaluation in order to see how at ease students are with several aspects of frontend development.
It includes creating useCase diagrams, basic product backlog and React structure components.

## Stack
Project consumes a given API by our tutor.

Project has been created using Vite and React. It is developped using TypeScript. Eventually some CSS will be added to the one given by Vite.

## Use project
First, you need to install the required dependancies. Use

```bash
npm install
```
in a terminal to get everything you need to see the result.

Then, use the following command to start the project:

```bash
npm run dev
```
If everything goes well, it should propose you to reach the website on port 5173.
